# Before start

`settings.local.json`에서 클로드 에이전트 팀 사용에 대한 옵션이 활성화되어 있는지 확인합니다.
비활성화 상태라면 활성화할 것을 사용자에게 요구합니다.
`~/.claude/settings.json` 혹은 `{project_root}/.claude/settings.local.json` 파일에 다음 내용이 있어야 합니다.
```json
{
  "env": {
    "CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS": "1"
  }
}
```

# Simple dev team 생성

## 개요

클로드 에이전트 팀을 생성합니다.

- 리더(id: 0): 계획 모드를 유지합니다. 유저로부터 명세를 전달받고, 계획을 수립합니다.
- 구현자(id: 1): 작성된 계획을 기반으로 코드 구현을 진행합니다.
- 리뷰어(id: 2): 구현자의 작업이 종료되면 코드 리뷰를 진행합니다.
- 반영자(id: 3): 리뷰어가 생성한 리뷰 내역을 코드에 반영합니다.

## 팀 메이트 세부 사항

### 리더(id: 0)

유저로부터 전달받은 명세를 기반으로 작업 계획을 수립합니다.
계획 작성이 완료됐다면, 유저에게 승인을 받고 구현자에게 구현을 위임합니다.

### 구현자(id: 1)

[구현 가이드](references/code-style-guide.md)과 기존 구현사항을 참고하여 계획된 내역을 구현합니다.
구현이 완료되면 구현 내용을 커밋합니다.

### 리뷰어(id: 2)

[리뷰 가이드](references/code-review-guide.md)를 참고하여 구현자가 구현한 코드를 리뷰합니다.
기본적으로, 코드 리뷰 내역은 반영자에 의해 모두 반영됩니다.
아키텍처를 위배하거나, 코드 스타일을 위배하더라도 반드시 수정이 필요한 내역의 경우는 리더 세션을 통해 사용자 동의를 받습니다.

### 반영자(id: 3)

리뷰어가 작성한 리뷰 내용을 모두 반영합니다. (옵션 1)
반영 작업이 완료되면 커밋합니다.

# 워크플로우

1. 리더가 계획을 수립합니다.
2. 구현자가 스토리 개발을 시작합니다.
3. 개발이 완료되면 리뷰어가 코드 리뷰를 진행합니다.
4. 리뷰가 완료되면 반영자가 리뷰 내역을 반영합니다.
5. 사용자로부터 추가적인 피드백을 받거나, 모든 팀메이트를 종료하고 팀을 제거할 것을 묻습니다.
